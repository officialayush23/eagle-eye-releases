# Eagle Eye releases

Windows x64 installers for Eagle Eye (control-cabinet QC from GA drawings and photos). Needs an NVIDIA GPU.

- EagleEye-0.1.0-Full-gpu-Setup.exe: everything included, works offline.
- EagleEye-0.1.0-Small-Setup.exe: small setup; downloads the runtime pack from this release.
- eagle-eye-verifier-model.zip + eagle-eye-verifier-runtime-gpu.zip: optional second opinion (Qwen3-VL-2B); unzip both into the same folder.
- SHA256SUMS.txt: checksums of every file.
